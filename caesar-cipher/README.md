    # Caesar Cipher

Aplikasi enkripsi/dekripsi **Caesar Cipher** (cipher substitusi abjad-tunggal) dengan Python.
Tugas mata kuliah IF4020 Kriptografi.

- Enkripsi: `c = (p + k) mod 26`
- Dekripsi: `p = (c - k) mod 26`
- Fitur tambahan: **brute force** (exhaustive key search) untuk kriptanalisis

## Cara menjalankan
```bash
python caesar.py
```

## Contoh
```
Plainteks : awasi asterix dan temannya obelix   (k = 3)
Cipherteks: dzdvl dvwhula gdq whpdqqbd rehola
```
