# Columnar Transposition Cipher

Aplikasi enkripsi/dekripsi **Columnar Transposition Cipher** (cipher transposisi) dengan Python.
Tugas mata kuliah IF4020 Kriptografi.

Plainteks ditulis per baris dalam matriks selebar panjang kata kunci, lalu dibaca
per kolom berdasarkan urutan alfabet huruf kata kunci. Baris terakhir yang kurang
diisi huruf dummy `X`.

## Cara menjalankan
```bash
python columnar.py
```

## Contoh
```
Plainteks : sistem dan teknologi informasi itb
Kunci     : TOMBAK
Cipherteks: EEGRTTTOOIMKIMBSNLFIIAONSSDNIA
```
