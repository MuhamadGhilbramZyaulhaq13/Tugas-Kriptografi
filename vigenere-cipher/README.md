# Vigenere Cipher

Aplikasi enkripsi/dekripsi **Vigenere Cipher** (cipher substitusi abjad-majemuk) dengan Python.
Tugas mata kuliah IF4020 Kriptografi.

- Enkripsi: `c_i = (p_i + k_i) mod 26`
- Dekripsi: `p_i = (c_i - k_i) mod 26`
- Kunci diulang sepanjang pesan; spasi dan tanda baca tidak diproses.

## Cara menjalankan
```bash
python vigenere.py
```
